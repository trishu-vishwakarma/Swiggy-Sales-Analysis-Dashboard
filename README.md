# 🍔 Swiggy Sales Analysis Dashboard

An interactive **Swiggy Sales Analysis Dashboard** built using **Microsoft Power BI** to analyze sales, orders, ratings, food types, cities, states, and sales trends.

 ## 📊 Dashboard Preview

![Swiggy Dashboard](./Swiggy_Dashboard.png)

## 🎯 Project Objective

The objective of this project is to analyze Swiggy sales data and create an interactive dashboard that helps understand:

- Overall sales performance
- Total orders and average order value
- Customer ratings
- Monthly, daily and weekly sales trends
- Sales by food type
- State-wise sales performance
- Top-performing cities
- Quarterly sales and order performance

## 🛠️ Tools & Technologies

- **Power BI**
- **Microsoft Excel / CSV**
- **Data Cleaning & Transformation**
- **Data Analysis**
- **Data Visualization**
- **DAX**

## 📈 Dashboard Features

### 1. Monthly Sales Trend
Shows how sales changed from January to August and helps identify monthly sales patterns.

### 2. Daily Sales Trend
Compares sales performance across different days of the week.

### 3. Weekly Sales Trend
Displays sales movement across the weeks to identify weekly patterns.

### 4. Sales by Food Type
Compares sales between **Veg** and **Non-Veg** food categories.

### 5. Sales by State
Interactive map visualization showing geographical sales performance across different states.

### 6. Top 5 Cities by Sales
Highlights the top-performing cities based on total sales.

### 7. Quarterly Performance
Provides a comparison of:

- Sales
- Ratings
- Orders

across different quarters.

### 8. Interactive Filters

The dashboard includes filters for:

- Months
- Category
- Restaurant Name

These filters allow users to interactively explore the data.

## 🔄 Data Analysis Process

The project followed these major steps:

1. Collected the sales dataset.
2. Cleaned and prepared the data.
3. Removed errors and handled inconsistent data.
4. Transformed the data using Power BI.
5. Created required calculations and KPIs.
6. Built interactive charts and visualizations.
7. Added slicers and filters for interactive analysis.
8. Designed the final dashboard for easy business reporting.

## 💡 Key Insights

The dashboard helps identify:

- Overall sales performance and order volume.
- Differences between Veg and Non-Veg sales.
- Top-performing cities.
- State-wise sales distribution.
- Monthly, daily and weekly sales patterns.
- Quarterly changes in sales and orders.
- Customer rating performance.
